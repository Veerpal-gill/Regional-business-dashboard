# Regional-business-Reports-powerbi

An interactive business-intelligence dashboard for exploring regional revenue, product-category performance, and sales trends in one place.

## Dashboard overview

The report brings together four complementary views:

- **Revenue by region** — compares sales across the Midwest, Northeast, West, and Southeast.
- **Revenue by category** — ranks product categories, including Fitness, Footwear, Apparel, Sports Equipment, Cycling, Aquatics, and Accessories.
- **Sales trend** — tracks revenue performance over time to highlight peaks, dips, and momentum.
- **Revenue share by category** — shows each category's contribution to total revenue.

Interactive category and region selectors make it easy to focus the analysis on the segments that matter.

## Key insights shown

- The Midwest leads regional revenue, with the Northeast close behind.
- Fitness is the highest-revenue product category, followed by Footwear and Apparel.
- Revenue is concentrated in a small number of leading categories, while the remaining categories provide a meaningful long tail.
- The sales trend highlights periodic spikes that can be investigated for promotions, seasonal effects, or high-performing campaigns.

## Using the dashboard

1. Select one or more **categories** to filter the report.
2. Select one or more **regions** to compare market performance.
3. Review the charts together to identify leading segments and sales patterns.
4. Clear or adjust selections to return to the full business view.

## Built for

- Regional sales performance reviews
- Product-category planning
- Leadership reporting
- Identifying growth opportunities and underperforming segments

## Data fields

| Field | Purpose |
| --- | --- |
| Region | Groups sales geographically |
| Category | Classifies products by line of business |
| Revenue | Measures sales value for comparisons and share analysis |
| Date / Period | Supports trend reporting over time |
